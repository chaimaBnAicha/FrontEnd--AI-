# Leave Calendar Component
This file represents the leave calendar functionality, including request management and approvals.

## Structure:
- Header with search and filters
- List of leave requests in a responsive table
- AI analysis integration via modal
- Status update buttons for actions

## Usage:
1. View all leave requests in a paginated table
2. Search and filter by status
3. Access AI analysis for each request
4. Approve/Reject leave requests
5. Download attached documents

## Dependencies:
- @ng-bootstrap/ng-bootstrap for modal
- ngx-pagination for pagination
- FontAwesome for icons
